# Finsurance

A modern, responsive financial and insurance website featuring interactive quote calculators, customizable coverage builders, comprehensive plan guides, and clean light/dark mode support.

## Features
- **Modern Responsive Design**: Optimized across mobile (360px), tablet (768px), and desktop (1024px+).
- **Interactive Tools**: Live Coverage Builder, interactive Plan Finder quiz, and instant Premium Estimator.
- **Dark / Light Mode**: Seamless theme switching with saved user preference.
- **Lucide Iconography & Google Fonts**: Crisp icons and typography.

## Pages
- `index.html` - Homepage with interactive coverage builder & trust stats
- `plans.html` - Comprehensive insurance plans with filters and interactive quiz
- `about.html` - Company mission, story, milestones, and leadership
- `contact.html` - Contact form, office info, social links, and live interactive map
- `login.html` & `register.html` - Secure client authentication portals
- `404.html` - Custom error page
